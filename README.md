# Bellabeat Case Study: Fitbit Smart-Device Usage Analysis
Google Data Analytics Capstone : Fitbit health tracker analysis with Power BI
## Business Question
What trends in smart-device usage can help Bellabeat, a wellness technology company, shape its marketing strategy?

## Data
- Fitbit Fitness Tracker Data (Mobius, Kaggle)
- 35 users, one month of activity (March-April 2016)
- Daily activity, calories, steps, and sleep data

## Tools
Power BI

## Process
1. Cleaned the data: removed duplicates, fixed date formats, handled missing values
2. Built the dashboard and measures in Power BI

## Key Findings
1. Only 7 of 35 users (20%) used their tracker 15 or more days in the month.
2. Wednesday (7.4k steps) and Saturday (7.1k) are the most active days. Tuesday (4.9k) is the least active.
3. Sleep and time in bed are strongly correlated (r = 0.93). Average sleep is 7h 22m, and users spend about 38 minutes awake in bed each day.
4. Every additional 1,000 steps is associated with about 88 more calories burned.
5. Very active minutes have the strongest link to steps, while sedentary minutes are negatively related.

## Recommendations for Bellabeat
1. Tuesday step challenge: send a reminder or mini challenge on the least active day.
2. Calorie-linked goals: show step goals as calories burned (for example, +1,000 steps is about +88 kcal).
3. Boost tracker usage: add streak badges or weekly summary notifications.
4. Add bedtime reminders to reduce the 38 minutes users spend awake in bed.

## Limitations
- Small sample (35 users) and only one month of data from 2016, so results may not generalize.
- Findings show associations, not causes.
